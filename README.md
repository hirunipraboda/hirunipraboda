## 🚀 Selected Projects

### 01 · TruthLens — AI Hallucination Detection & Verification System

**Tech Stack:** Node.js · Express.js · React Native · MongoDB Atlas · REST APIs · Render

An AI-powered verification platform designed to detect, analyze, and verify hallucinations in AI-generated responses through automated claim extraction, multi-source external verification, and neural confidence scoring.

**Key Features & Focus Areas**

- Automated extraction of factual, statistical, and historical claims from AI responses.
- Multi-source fact verification classifying statements into Verified, Contradicted, or Unverifiable.
- Source credibility assessment evaluating authority, recency, and source trustworthiness.
- Confidence scoring and hallucination mitigation risk metrics.
- Production architecture with decoupled Node.js/Express backend on Render and cross-platform React Native client.

🔗 **Repository:** [AI-Hallucination-Detection-and-Verification-System](https://github.com/hirunipraboda/AI-Hallucination-Detection-and-Verification-System)

### 02 · SmartFold — Laundry Operations & Management System

**Tech Stack:** Java 17 · Spring Boot 3 · Spring Data JPA · Spring Security · MySQL / H2 · JavaScript (ES6)

A full-stack enterprise laundry and dry-cleaning operations platform engineered to optimize commercial workflows, provide customer self-service booking, and streamline administrative management.

**Key Features & Focus Areas**

- Customer ordering workflow with dynamic price calculation across service categories.
- Operations dashboard providing live analytics on daily orders, revenue, and queue status.
- Visual order tracking pipeline from initial booking through processing stages to pickup/delivery.
- Role-based access control (RBAC) implemented via Spring Security isolating admin consoles and user portals.
- In-app customer messaging channel and support for online and cash-on-pickup settlements.

🔗 **Repository:** [Laundry_Management_System](https://github.com/hirunipraboda/Laundry_Management_System)

### 03 · Toxic Comment Classification & NLP Pipeline

**Tech Stack:** Python · NLP & NLTK · Scikit-Learn · Pandas · NumPy · TF-IDF · Matplotlib

An end-to-end natural language processing pipeline engineered to detect and classify toxic online discourse, featuring automated text preprocessing, feature engineering on 16,000 comments, and multi-algorithm benchmarking.

**Key Features & Focus Areas**

- Comprehensive text preprocessing: tokenization, punctuation removal, stopword filtering, and lemmatization.
- Feature extraction using n-gram TF-IDF vectorization on a balanced 16,000-comment corpus.
- Multi-model evaluation comparing 6 algorithms (Linear SVM, Logistic Regression, Naive Bayes, Random Forest, Decision Tree, KNN).
- Systematic hyperparameter tuning with GridSearchCV and cross-validation to maximize classification recall.
- Interactive inference module for real-time text toxicity scoring and confidence classification.

🔗 **Repository:** [ToxicCommentClassificationNLP](https://github.com/hirunipraboda/ToxicCommentClassificationNLP)

### 04 · Green Weather Guard — IoT Greenhouse Automation

**Tech Stack:** ESP32 · C/C++ (Arduino) · DHT11/DHT22 · MQ135 · Blynk IoT · Embedded Systems

An automated IoT microclimate control system designed to continuously monitor greenhouse conditions and autonomously regulate internal growing environments via sensor telemetry and cloud connectivity.

**Key Features & Focus Areas**

- Continuous multi-sensor telemetry tracking ambient temperature, relative humidity, and CO₂ concentrations.
- Automated multi-actuator regulation of ventilation fans, heating elements, ultrasonic misters, and grow lights.
- Real-time cloud synchronization and remote manual override via the Blynk IoT mobile dashboard.
- Self-healing Wi-Fi reconnection logic to ensure persistent, uninterrupted telemetry streaming.
- Hardware-isolated 4-channel relay circuitry protecting low-voltage microcontroller GPIO pins.

🔗 **Repository:** [Green_Weather_Guard](https://github.com/hirunipraboda/Green_Weather_Guard)

### 05 · TourLink — AI-Powered Smart Tourism Platform

**Tech Stack:** ASP.NET Core (.NET 8) · React 19 · TypeScript · Flutter · PostgreSQL · Agentic AI · Render

A full-stack smart tourism ecosystem that combines destination discovery, personalized trip planning, and automated itinerary generation powered by a four-agent AI orchestration subsystem and cross-platform clients.

**Key Features & Focus Areas**

- Four-agent AI orchestration: specialized agents for Destination Research, Route Optimization, Budget Feasibility, and Master Itinerary Assembly.
- High-performance backend powered by C# ASP.NET Core Web API (.NET 8), Entity Framework Core, and Supabase PostgreSQL.
- Multi-client frontend: modern React 19 TypeScript web platform and Flutter mobile application.
- Route and financial optimization calculating inter-city transit sequences, travel duration, and budget feasibility.
- Production multi-service cloud architecture deployed live on Render (Frontend, Web API, and AI worker nodes).

🔗 **Repository:** [tourism-planner](https://github.com/hirunipraboda/tourism-planner)

### 06 · TrainTrack Sri Lanka — Railway Passenger Platform

**Tech Stack:** React 18 · Node.js · Express.js · MongoDB Atlas · Tailwind CSS · Render

A dedicated public transit web platform engineered for Sri Lanka Railways commuters, travelers, and tourists to solve scheduling uncertainties, ticket pricing questions, and commuter reporting needs.

**Key Features & Focus Areas**

- Timetable lookup across Sri Lankan railway lines (Coast, Main, Northern) with intermediate halt stop schedules.
- Multi-class fare calculation engine supporting 1st Class AC, 2nd Class, and 3rd Class tariffs with passenger multipliers.
- Crowd-sourced issue reporting system generating trackable reference IDs (TT-XXXX) for train delays and carriage issues.
- Multi-dimensional passenger review system (Punctuality, Cleanliness, Comfort, Staff) with MongoDB aggregation metrics.
- Production deployment on Render with React 18 frontend and Node.js/Express backend connected to MongoDB Atlas.

🔗 **Repository:** [traintrack-web](https://github.com/hirunipraboda/traintrack-web)
